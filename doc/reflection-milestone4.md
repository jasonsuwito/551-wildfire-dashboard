### Final Reflection

Our interactive dashboard provides a comprehensive analysis of Canadian wildfire data spanning 2013-2023. The design features a landing page and a primary dashboard application with tabbed navigation, offering insights into wildfire causes, locations, and trends. Users have the ability to filter data by time frames and access key statistics to support deeper analysis.

Incorporating feedback from Milestone 3, we addressed concerns regarding the clarity of fire cause labels. Previous releases featured labels that were challenging to interpret (I.e., “H”, “U”, “N”), an issue identified by peer reviews that had initially been overlooked. To improve user experience, we updated the pie chart to display formal names for each fire cause designation and removed the legend from the line graph for better visual clarity and positioning. We globally applied province and year filters across the dashboard, allowing users to filter data by specific location and time period. Additionally, the wildfire bar plot was modified into provincially aggregated data to enable evaluation of fire counts per year. Peer feedback received commented on inability to view exact wildfire location names. As our dataset contains only latitude and longitude, displaying precise city or regional names is infeasible. To address this, we leveraged Plotly capabilities to overlay wildfire locations on an interactive map. Allowing users to view provincial boundaries and regional location names upon zooming in. Additionally, displaying the ‘Month’ as a continuous variable was misleading, so this was updated as categorical, displaying individual month numbers instead. The colour schemes for categorical features on the map (I.e., “Cause”, “Response” and “Month”) were adjusted to align with the dashboard theme. “Cause” colours were set manually, while the legend for the “Month” feature was updated to a more intuitive palette - red shades for warmer months and blue shades for cooler months. Furthermore, the count of “Fire IDs” was eliminated, as a similar view is presented on the landing page. Approximately 70% of the responses were blank for the “Response” field, and after reviewing the metadata, we determined that the abbreviations were not meaningful, so this field was also removed.

A further review of the layout prompted us to reduce the width of the cards and increase the map size for improved data visibility. The colour of the year slider was corrected to align with the overall theme of the dashboard. We considered the general feedback regarding colour choices, such as using the different colours per province in the line plot and the overall darkness of the dashboard. However, since the colours were selected to reflect the thematic representation of wildfire data, we decided to retain the existing colour scheme and did not implement these changes. Our filters offset some of these concerns as well, as users are able to isolate for specific provinces.

Our goal was to create a dashboard tailored for policymakers within the Government of Canada to assess the provincial impact of wildfires in National Parks. However, we expanded the scope to include comprehensive provincial data for a broader analysis. We envision this dashboard as a tool to justify federal climate change funding, particularly for British Columbia, and we believe that it effectively supports this objective.
